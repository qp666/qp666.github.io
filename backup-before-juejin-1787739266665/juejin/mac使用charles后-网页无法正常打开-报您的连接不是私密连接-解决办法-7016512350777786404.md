问题:最近发现一打开charles,mac在浏览器中就不能打开网页。

情况如下：

解决办法1:关闭wifi代理中的网页代理(ps:每次打开charles都需要重新去wifi代理中关闭,挺麻烦的......)

(1):在设置中的网络里点高级

(2):取消勾选网页代理与安全网页代理

(3):点击好以后回到设置中的网络页面,点击应用即可

解决办法2:mac添加charles的证书(ps:一劳永逸,推荐!)

(1):在chalres的help的SSL Proxying 选择 Install Charles Root Certificate 安装证书

(2):安装证书完毕以后会自动弹出钥匙串,找到Charles的证书,此时证书是不被信任的

(3):双击此证书,在信任中选择始终信任后关闭窗口,使用账号密码授权后即可生效
