# 个人简历

卿鹏的交互式在线简历（hacknical 风格）。

**线上地址：** https://qp666.github.io

## 技术栈

- Vite + React 19 + TypeScript
- Tailwind CSS 4
- Framer Motion
- Recharts（技能雷达图）

## 本地开发

```bash
pnpm install
pnpm dev         # http://localhost:5173
pnpm build       # 输出到 dist/
pnpm preview
```

### Vercel（备选）

```bash
vercel login
npx vercel --prod
```
