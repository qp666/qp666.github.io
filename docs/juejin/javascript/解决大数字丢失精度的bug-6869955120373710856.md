#### 2.在发送请求的js文件下导入 import JSONbig from 'json-bigint'

#### 3.在发送请求的response响应时把return response.json() 改为 return response.text()

#### 4\. .then返回时再做一层处理把返回的 json = JSONbig.parse(json)
