```css
border-bottom: 1px solid #eceef0;
  box-shadow: 0 1px 1px #fff;
```

先设置一个1px粗的border-bottom，这个时候在大部分移动设备上会呈现出很粗的线，然后再使用白色CSS阴影，并且偏移1px来压住过粗的border-bottom线，结果就看到了一条细线产生。
