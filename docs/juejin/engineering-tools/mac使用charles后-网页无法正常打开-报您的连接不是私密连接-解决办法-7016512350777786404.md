### 问题:最近发现一打开charles,mac在浏览器中就不能打开网页。

#### 情况如下：

![image.png](https://p1-juejin.byteimg.com/tos-cn-i-k3u1fbpfcp/1cc59c6929b64b1f8d96999e5e1084c7~tplv-k3u1fbpfcp-zoom-in-crop-mark:1512:0:0:0.awebp?)

### 解决办法1:关闭wifi代理中的网页代理(ps:每次打开charles都需要重新去wifi代理中关闭,挺麻烦的......)

#### (1):在设置中的网络里点高级

![image.png](https://p6-juejin.byteimg.com/tos-cn-i-k3u1fbpfcp/667b87f7a94047c2811b825fb3e6d2d3~tplv-k3u1fbpfcp-zoom-in-crop-mark:1512:0:0:0.awebp?)

#### (2):取消勾选网页代理与安全网页代理

![image.png](https://p9-juejin.byteimg.com/tos-cn-i-k3u1fbpfcp/3e49cd2dcf2f4bd5904469de49ea6d7b~tplv-k3u1fbpfcp-zoom-in-crop-mark:1512:0:0:0.awebp?)

#### (3):点击好以后回到设置中的网络页面,点击应用即可

![image.png](https://p9-juejin.byteimg.com/tos-cn-i-k3u1fbpfcp/5b94750a501843d2a8b4e6527962c6ca~tplv-k3u1fbpfcp-zoom-in-crop-mark:1512:0:0:0.awebp?)

### 解决办法2:mac添加charles的证书(ps:一劳永逸,推荐!)

#### (1):在chalres的help的SSL Proxying 选择 Install Charles Root Certificate 安装证书

![image.png](https://p6-juejin.byteimg.com/tos-cn-i-k3u1fbpfcp/a96613da635a4d2ea2790d5d8be47446~tplv-k3u1fbpfcp-zoom-in-crop-mark:1512:0:0:0.awebp?)

#### (2):安装证书完毕以后会自动弹出钥匙串,找到Charles的证书,此时证书是不被信任的

![image.png](https://p3-juejin.byteimg.com/tos-cn-i-k3u1fbpfcp/fe11881700a940cdb537eab3a05af37f~tplv-k3u1fbpfcp-zoom-in-crop-mark:1512:0:0:0.awebp?)

#### (3):双击此证书,在信任中选择始终信任后关闭窗口,使用账号密码授权后即可生效

![image.png](https://p3-juejin.byteimg.com/tos-cn-i-k3u1fbpfcp/6c955a0be5ff462e800e2cc322c1c923~tplv-k3u1fbpfcp-zoom-in-crop-mark:1512:0:0:0.awebp?)
