安装使用
----

### 一.先安装node-sass，因为sass-loader依赖于它

```css
npm install node-sass --save-dev
```

### 二.安装sass-loader

```css
npm install sass-loader --save-dev
```

### 三.在项目中使用

```ini
<style lang="scss">
```

编译失败时的解决办法
----------

### 一.使用cnpm下载

```css
cnpm install node-sass --save-dev
cnpm install sass-loader --save-dev
```

### 二.修改package.json中的node-sass和sass-loader版本,建议修改成下面的版本

```json
"node-sass": "^4.0.0",
"sass-loader": "^7.3.1",
```
