bug如下:
------

终端不报错,控制台报错的地方并没有指向vue中某行代码.而是指向router,经过排查才发现是?.链式运算符出错,导致白屏.

![image.png](https://p3-juejin.byteimg.com/tos-cn-i-k3u1fbpfcp/668b7fa899454aeb95d6d71271d9e2e1~tplv-k3u1fbpfcp-jj-mark:3024:0:0:0:q75.awebp#?w=716&h=473&s=48374&e=png&b=1e1e1e)

修复方案
----

下载依赖

```sql
npm install rollup-plugin-esbuild
```

vite.config.js中引入,并增加配置

```javascript
import esbuild from 'rollup-plugin-esbuild'
export default defineConfig({
  plugins: [
    {
      ...esbuild({
        target: 'chrome70',
        // 如有需要可以在这里加 js ts 之类的其他后缀
        include: /\.vue$/,
        loaders: {
          '.vue': 'js',
        },
      }),
      enforce: 'post',
    },
  ],
})
```

重新运行项目,发现错误已经消失,页面正常打开 ...end
