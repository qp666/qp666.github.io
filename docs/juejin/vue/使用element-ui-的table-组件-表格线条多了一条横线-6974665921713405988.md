开发中突然遇到下面的的问题,表格中多了一条横线,怪丑的,百度了半天,终于找到了一个正确的解决办法. ![image.png](https://p1-juejin.byteimg.com/tos-cn-i-k3u1fbpfcp/65a2cfc2c31642b7b4deedf8cb641843~tplv-k3u1fbpfcp-zoom-in-crop-mark:1512:0:0:0.awebp)

在app.vue中加入下面的代码

```css
body .el-table::before {
    z-index: inherit;
}
```
