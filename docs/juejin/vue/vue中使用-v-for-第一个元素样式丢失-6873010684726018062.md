#### 问题:第一个样式丢失,发现少了data-v-xxxxxxxx;

#### 查看代码后发现只是一个vfor循环并没有什么特别的

```ini
<van-cell v-for="item in filterHouseList" :key="item.house_id" :title="item.houseStr" />
```

#### 看了好几篇帖子才知道是vant的cell渲染问题,于是换成div重写,问题解决

```css
<div v-for="item in filterHouseList" :key="item.house_id" class="list_title">
  &#123;&#123;item.houseStr&#125;&#125;
 </div>
```
